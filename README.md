# Sticker Pop Parade

A fun, mobile-first balloon popping game for kids! Pop balloons, earn points, and collect stickers.

## Quick Start

```bash
cd /workspace/game
npm install
npm run dev
```

Open: http://localhost:18888/game

## How to Play

- Tap balloons to pop them (10 points each)
- Every 50 points unlocks a new sticker
- View your sticker collection in the Gallery
- Turn on Adult Lock Mode to prevent accidental exits

## Adult Lock Mode

1. Open Settings (⚙️)
2. Tap "Adult Lock Mode"
3. To exit: Hold the Exit button for 3 seconds while using two fingers

**Note:** For true device lock, use Android Screen Pinning or iOS Guided Access.

## Installing as App (PWA)

### Android (Chrome)
1. Open the game in Chrome
2. Tap menu → "Add to Home screen"
3. Follow prompts to install

### iOS (Safari)
1. Open the game in Safari
2. Tap Share button → "Add to Home Screen"
3. Confirm to install

The game works offline once installed!

## Features

- 🎈 Colorful balloon popping fun
- ⭐ Collectible stickers
- 🔒 Adult Lock Mode with exit gate
- 📱 Works offline as PWA
- 🔊 Cheerful sounds (with mute option)
